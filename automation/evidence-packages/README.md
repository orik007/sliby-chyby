# Unpublished evidence package queue

This durable queue on the audit branch retains the evidence packages of a run whose collection, print splitting, screening, routing, and relevance checks all succeeded. A package holds every kept law change of one promise in full, with the party's attributable conduct on it. It is operational audit data and never changes public data, a score, or publication status.

Each current package is the input for the two independent assessors. A changed package supersedes the prior version for that promise, and a promise that no longer gets a package has its current package withdrawn; every version remains auditable. A package larger than the assessors' normal-price input limit is kept with `blockedReason: "oversized"`, is never trimmed or assessed automatically, and waits for human review.

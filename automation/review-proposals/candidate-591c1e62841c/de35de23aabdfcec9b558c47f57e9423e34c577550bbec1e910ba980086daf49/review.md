# Dotační program pro školní sportovní kluby

> Nezveřejněný návrh k lidské kontrole. Ani schválení tohoto souboru samo nic nezveřejňuje a nemění SLAVA Index.

## Návrh pro veřejný web

Toto je jediná část dokumentu určená jako kandidát veřejného textu. Musí být srozumitelná bez znalosti projektu, práva nebo fungování Poslanecké sněmovny.

### Hodnocení

**Směřuje ke splnění (+1)**

### Vysvětlení

Poslanci ANO hlasovali pro návrh zákona, který mění pravidla podpory sportu, a po jeho zamítnutí Senátem hlasovali také pro setrvání Sněmovny na návrhu. Schválené znění odstraňuje výjimku, která vylučovala školní sport z uvedené podpory, a výslovně počítá s podporou sportovních organizací. Jde tedy o krok, který může podpořit část slibu, ale zákon nezavádí zvláštní dotační program pro školní sportovní kluby ani nespojuje podporu s aktivitami, soutěžemi a tréninky pro všechny věkové skupiny.

- Dokládají uvedené zdroje všechna podstatná tvrzení a nechybí rozporný podklad?

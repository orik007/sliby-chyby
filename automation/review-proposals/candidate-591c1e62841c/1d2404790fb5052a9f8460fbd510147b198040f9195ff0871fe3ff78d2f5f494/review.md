# Dotační program pro školní sportovní kluby

> Neveřejný návrh k lidské kontrole. Ani schválení tohoto souboru samo nic nezveřejňuje a nemění SLAVA Index.

## Návrh pro veřejný web

Toto je jediná část dokumentu určená jako kandidát veřejného textu. Musí být srozumitelná bez znalosti projektu, práva nebo fungování Poslanecké sněmovny.

### Hodnocení

**Směřuje ke splnění (+1)**

### Vysvětlení

Původní návrh poslanců ANO v části o sportu upravoval pravidla fungování sportovní agentury, nikoli dotační program pro školní kluby. Poslanci ANO pak hlasovali pro znění, které rozšiřuje podporu sportovních organizací a pohybových aktivit a ruší výjimku pro školní a vysokoškolský sport. Po zamítnutí návrhu Senátem Sněmovna setrvala na svém znění a poslanci ANO je znovu podpořili. Tato změna může školní sport zpřístupnit širší dotační podpoře, ale samostatný program pro školní sportovní kluby s aktivitami pro všechny věkové skupiny nezavádí.

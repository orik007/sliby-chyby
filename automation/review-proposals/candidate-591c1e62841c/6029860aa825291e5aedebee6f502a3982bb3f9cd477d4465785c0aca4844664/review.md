# Dotační program pro školní sportovní kluby

> Nezveřejněný návrh k lidské kontrole. Ani schválení tohoto souboru samo nic nezveřejňuje a nemění SLAVA Index.

## Návrh pro veřejný web

Toto je jediná část dokumentu určená jako kandidát veřejného textu. Musí být srozumitelná bez znalosti projektu, práva nebo fungování Poslanecké sněmovny.

### Hodnocení

**Směřuje ke splnění (+1)**

### Vysvětlení

Poslanci ANO hlasovali pro změnu zákona o podpoře sportu, která odstraňuje výjimku pro školní sport a rozšiřuje oblasti státní podpory sportu. Senát návrh odmítl, ale Poslanecká sněmovna po jeho vrácení setrvala na schváleném znění. Tato změna může otevřít podporu školním sportovním klubům, a proto představuje dílčí posun ke slibu. Samostatný dotační program pro kluby pořádající mimoškolní aktivity, soutěže a tréninky ale výslovně nezavádí.

## Co má zkontrolovat reviewer

- Jsou zkratky, právní pojmy a úřední označení při prvním použití vysvětlené?
- Dokládají uvedené zdroje všechna podstatná tvrzení a nechybí rozporný podklad?
